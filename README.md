# WhatsApp_Bot
Whatsapp bot to reply to answer quickly using LLM

## Resume Description
**Full-stack WhatsApp automation platform** featuring AI-powered message responses using OpenAI/Google Gemini APIs, built with Node.js/Express backend, React/Material-UI dashboard, Socket.IO real-time communication, and MongoDB for analytics and message management.

**Intelligent messaging bot** that automates WhatsApp communication with LLM integration for context-aware responses, includes RESTful API, WebSocket support, contact management, and a comprehensive admin dashboard for monitoring message analytics and bot configuration.
